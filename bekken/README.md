# 🧘 Bekken & Heupen

Mobiele webapp (PWA) met dagelijkse oefeningen tegen een te sterke voorwaartse bekkenkanteling
en voor heupmobiliteit: begeleide timer, herhalingsteller, afvinken, weekschema, voortgang en herinnering.

- Live: `https://liacicalvinn.github.io/plant-tracker/bekken/`
- Op je telefoon: open de link in Chrome/Safari → *Toevoegen aan startscherm*.
- Geen backend: alle gegevens staan in de browseropslag van je toestel (back-up via *Meer*).
- Oefeningen, routines en dosering staan in `js/data.js`.
